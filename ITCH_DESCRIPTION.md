# Shark Attackers of SPLORR!!

*A metaphor about the sea. And sharks.*

You start on a pier. There is a boat. Beyond the pier is open water, and in open water there are sharks.

Climb aboard, cast off, pick a heading and a speed, and sail. The further you get from the pier, the more likely it is that something is waiting for you.

**HOW TO PLAY**

It is a turn-based game of menus. Click a button to do the thing on the button. Set Heading and Set Speed ask for a number. The game moves when you move.

Your game is saved in your browser as you go, so you can close the tab and come back to where you were.

**ABOUT**

Made by TheGrumpyGameDev for The Wacky Fun Game Jam of Joy and Whimsy, with sponsorship from UMLAUT.FYI and Pen 15.

The original was written in VB.NET. This browser version is a rebuild in Odin compiled to WebAssembly, made in October 2026 with Claude Code (Claude Sonnet 5.5). Claude wrote the code and the tests; I chose the design, made every decision and played every build.
